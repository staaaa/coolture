# 🎭 Coolture - Cultural Events Discovery App (PWA)

## 🌍 About the Project
The goal of this project is to develop a **Progressive Web Application (PWA)** with strong **social features** that helps users **discover and participate in cultural events** more easily.  
To achieve this, the application will provide:
- A wide range of **filters** for event search  
- An **interactive map** for visual exploration  
- An **intelligent recommendation system** that adapts to users’ interests and location  

Our main challenges include:
- **Collecting and maintaining accurate event data** 🗂️  
- **Verifying user-generated content** to ensure quality and reliability  
- **Delivering an intuitive user experience (UX)** combined with a **visually appealing interface (UI)** 🎨
